# 隱私權政策

[English](PRIVACY.md) · **繁體中文** · [简体中文](PRIVACY.zh-Hans.md)

_最後更新：2026-10-27_

DiskLens 是一個完全在你的 Mac 上執行的磁碟空間分析工具。這份政策說明它會接觸哪些資料，以及這些資料會去哪裡。簡單來說：**DiskLens 不收集任何資料，也不會把資料傳到任何地方。** 唯一的例外是選用的 AI 功能：你必須自己開啟，而且它只會把少量檔案資訊交給你已經安裝好的 AI 工具。

## DiskLens 會讀取什麼

- **你掃描的資料夾的檔案系統資訊**：名稱、路徑、大小、修改日期、項目數量。DiskLens **不會**開啟或讀取檔案的內容。
- **已安裝 App 的 `Info.plist`**（名稱、bundle ID、圖示），用來判斷某個資料夾屬於哪個 App。
- **磁碟資訊**（總容量、可用空間、可清除空間）和本機 Time Machine 快照清單。

如果你開啟了「完整磁碟取用權限」，DiskLens 可以讀取 macOS 平常保護的資料夾（郵件、訊息、Safari 等）的檔案資訊。這個權限只用來計算大小。

## DiskLens 會儲存什麼

所有東西都留在你的 Mac 上：

- 掃描結果只在 App 開著時存在記憶體中。
- 設定（例如你選的 AI 工具、同意使用的日期）存在 App 的偏好設定檔（`~/Library/Preferences/tw.pg72.disklens.plist`）。
- 如果你用了 AI 功能，回答會快取在 `~/Library/Application Support/DiskLens/`，同樣的問題就不必再問一次。這份快取可以在「設定」裡清除。

## DiskLens 會傳送什麼

**什麼都不傳。** DiskLens 沒有分析、遙測、當機回報、帳號、廣告或更新伺服器，本身也不會發出任何網路連線。

### 選用的 AI 功能

如果你選擇使用「問 AI」，可以從下列工具中擇一使用。第一次使用某個工具前，DiskLens 會顯示同意畫面，寫明要使用哪個工具，並讓你預覽實際會送出的文字。

- **Apple 裝置端模型**（Apple Intelligence；Mac App Store 版只提供這個選項）：由你 Mac 上的 Apple 內建模型處理，**不會透過網路傳送任何資料**。
- **你自己安裝並登入的 AI 命令列工具**（例如 Claude Code、Codex、Antigravity、opencode；僅限直接下載版）：以下說明適用於這類工具。

- **送給該工具的內容**：你選取的項目的路徑與名稱、大小、日期、項目數量、所選資料夾裡最大的幾個項目的名稱，以及 DiskLens 自己的分類結果。**絕不會送出檔案內容。**
- **資料會去哪裡**：該工具會用**你的**帳號把這些文字傳給它的廠商（例如 Anthropic、OpenAI、Google）。廠商依照它自己的隱私權政策和條款處理這些資料，而且可能會計入你方案的用量。
- **該工具能做什麼**：DiskLens 會在一個空的暫存資料夾裡，以唯讀、不能使用任何工具的模式啟動它。回答只會被顯示出來，絕不會刪除、搬移或修改任何東西。
- 你隨時可以到 **設定 → AI** 撤回同意或關閉這個功能。

## 意見回饋與問題回報

只有在**你**選擇送出時才會回報：

- **透過 Email**（寄到 developer@pg72.tw）或 **GitHub**。DiskLens 只會打開你的郵件 App 或瀏覽器並準備好草稿，你自己按下送出之前，什麼都不會傳出去。
- 草稿會附上一段標示清楚的**診斷資訊**：App 版本與建置號、版本類型、macOS 版本、機型、介面語言。**不含任何檔案、路徑或掃描結果**，送出前你可以修改或刪除。
- Email 只會用來回覆你和修正問題。GitHub 上的 issue 是公開的，適用 GitHub 的條款。

## 刪除檔案

DiskLens 只會在你確認之後把項目移到垃圾桶，而且會拒絕動到受保護的系統位置。在你清空垃圾桶之前，項目都可以復原。

## 兒童

DiskLens 是一般用途的工具，不收集個人資料，也不是針對兒童設計的。

## 政策變更

這份政策的修改會發布在這個 repo 中，並更新最上方的日期。
